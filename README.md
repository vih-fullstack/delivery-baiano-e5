# delivery-baiano-e5
Projeto de desenvolvimento de uma plataforma de pedidos e entregas online. O objetivo é simular o ecossistema completo de um app de delivery, integrando catálogo de produtos, carrinho de compras, acompanhamento de pedidos em tempo real e painel administrativo.
